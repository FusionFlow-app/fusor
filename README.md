**Fusor** is a powerful, terminal-based user interface (TUI) for designing and orchestrating workflows. Built entirely in Go, it brings modern, visual flow editing directly to your terminal. 

With an integrated AI chat, you can describe the workflow you want, and the agent will help you build it block by block without leaving your command line.

> [!WARNING]
> **Fusor is currently in active development.** The project is experimental and the only way to run it is by building from source. Expect breaking changes and incomplete features.

## 🚀 Getting Started

Since Fusor is in development, there are no pre-built binaries available yet. You must compile it from source.

### Prerequisites

- Go 1.21 or later installed on your system.

### Build & Run

Clone the repository and run the main entry point:

```bash
# Clone the repository
git clone https://github.com/FusionFlow-app/fusor.git
cd fusor

# Build and run the app
go run ./cmd/fusor
```
